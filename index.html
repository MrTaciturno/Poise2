Ficha Interativa - Ajuda & Atalhos

Modo Designer (Edição de Campos)

  • Adicionar Campos: Use os botões na barra lateral para criar novos inputs.
  • Mover: Clique e arraste um campo para reposicioná-lo na planilha.
  • Redimensionar: Arraste a alça no canto inferior direito de um campo.
  • Editar Propriedades: Clique em um campo no modo de edição para abrir o painel de propriedades na barra lateral.
  • Navegação Fina (Nudge): Use as setas do teclado (↑, ↓, ←, →) para mover o campo selecionado em 0.1% de precisão. Segure Shift para mover 1%.
  • Deletar: Selecione um campo e aperte a tecla Delete ou clique em "Deletar Campo".

Geral

  • Exportar para PDF: O botão "Exportar PDF" abre a caixa de diálogo de impressão do navegador configurada automaticamente para ocultar toda a interface de edição e barra lateral, imprimindo perfeitamente apenas a ficha com seus preenchimentos.
  • Salvar Ficha (.poise): Exporta todas as posições dos campos e o texto preenchido. Se você carregou uma imagem customizada, o arquivo incluirá a imagem para que a ficha seja auto-suficiente!
